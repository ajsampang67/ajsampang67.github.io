Wigi

Flutter Web App

WIGI is short for "Wherever I'm going, I'm happy you're coming". It's a line from our first dance song, Pretty Boy by The Neighbourhood. This is a list of locations Alyssa and I have been throughout our time together.

It is a simple widget-based app written in Dart with Flutter. Very similar to Javascript with React Native. The app took about a month to create, from knowing nothing about Dart/Flutter to what you're looking at now. It's deployed on an EC2 instance using docker-compose, served via AWS alongside my personal website.
